# GMIT College app: build the APK

1. Create a free account at github.com and make a new repository.
2. Upload ALL files from this folder (including the hidden .github folder) to it.
3. Open the repository's Actions tab. The "Build APK" workflow runs by itself (about 5 minutes).
4. Open the finished run and download the "gmit-college-apk" artifact. Unzip it to get app-debug.apk.
5. Copy the APK to your phone and install it (allow "Install unknown apps" if asked).
